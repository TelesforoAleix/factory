# Project Agents

Project-local copy or sync target for reusable Factory roles, departments, skills, prompts, and local overrides.

Canonical definitions live in the Factory repository:

- `agents/role-registry.md`
- `agents/roles/`
- `agents/departments/`
- `prompts/factory/`

Use this folder when a standalone project workspace needs local access to those definitions without storing day-to-day ops state in the Factory repository.
