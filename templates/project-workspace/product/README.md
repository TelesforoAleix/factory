# Product

Project product, application, tool, or artifact work lives here.

Use [Project Discovery Brief](DISCOVERY.md) and [Product Roadmap And Version Plan](ROADMAP.md) before the first execution loop so objectives, scope, version slices, and postponed decisions are visible.

Execution agents edit this folder when tickets call for implementation. Product code should stay separate from Factory operating records in `ops/` and reusable Factory definitions in `agents/` or `.github/`.
